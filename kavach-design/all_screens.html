Screen flow map

50 app screens cover the main journeys. Validation, confirmations, cancellations and routine outcomes use the reusable popup/sheet patterns below instead of separate full-screen artboards.

Onboarding · 01–09

01 Splash → 02 Welcome → 03 Phone sign-in → 04 Code → 05 Permissions → 06 Profile → 07 PIN → 08 First contact → 09 Home. Invalid/expired code, permission denial, PIN mismatch/confirmation and contact selection are inline or modal states.

Home and Trusted Circle · 09–11

09 Home → 10 Trusted Circle → 11 Contact options. Home keeps SOS, Safe Journey, Trusted Circle, Fake Call, Safety Mode, Find Help, Offline Safety Kit and Readiness Checkup directly accessible. Settings 28 contains trigger setup, Voice SOS, Phone & Battery, Decoy Calculator, Privacy Center, language and data controls. Add-contact form, picker handoff, validation/duplicate, remove confirmation, test-message preview and result use sheets/dialogs.

SOS · 12–13, 37–39

09 Home → 12 Countdown → 13 PIN cancel or SOS review sheet → 38 Status. Wrong PIN and cancellation are dialogs; send failure, sent-but-unconfirmed, verified delivery and recorded acknowledgement appear as status variants, never as equivalent outcomes. 39 is the trusted-contact view. Emergency call confirmation/handoff remains in Help; Active Safe Walk has a persistent Call 112 control.

Vault and Shield · 14–22

Vault 14 → add-evidence sheet → 15 Case timeline → 16 Export preview; 14 also opens 49 Saved Recordings. Capture, permission, save and export outcomes use sheets or inline feedback. Shield 17 → 18 Message input → 19 Analysis progress → 20 Result; image 17 → 21 Check image → 22 Result. Validation and service-unavailable states use inline feedback/sheets.

Safe Journey and Safety Map · 23–26

09 Home → 23 Start Journey → 24 Automatic Monitoring. Location sharing stays within Safe Journey. Arrival detection is a static concept for supported devices; delayed journeys offer arrived, running late, and Call 112 choices. Location updates may pause due to permissions, signal, battery, or background limits. Map 25 → Report a spot 26. Safety Map distinguishes reported concerns, poor lighting, police stations, and the user location; reports remain unverified.

Help, Settings and Assurance · 27–39

Help 27 → call handoff or Guided Help 34. Settings 28 keeps Voice SOS 29, Phone & Battery 30, Decoy Calculator 31, Fake Call setup 40, Privacy Center 33, language and data controls. Home → Offline Safety Kit 32 and Readiness 35; Readiness 35 → response plan 36 or simulation 37. SOS status 38 and recipient view 39 remain separate context screens.

Fake Call · 40–43

Home 09 → 41 incoming call → 42 simulated conversation → 43 call ended. Screen 40 contains optional caller and timing customization. The call is simulated and never connects to a person. SOS remains visible during the call presentation.

Safety Mode · 44–50

Home 09 → Safety Mode 44 → Start audio or Start video → 46 audio or 47 video recording when access is already available. Screen 45 appears only when access is needed, and 50 shows unavailable access. Stop → 48 → 49 saved recordings. Recording does not trigger SOS.
